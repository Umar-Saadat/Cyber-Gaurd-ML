Preprocessing & Data Cleaning Pipeline

The preprocessing pipeline applies industry-standard cleansing tailored for network flow calculations to guarantee zero data leakage.

1. Header Sanitization

Trims leading/trailing whitespace across all 79+ column headers (e.g. ' Flow Duration' → 'Flow Duration').

2. Infinite Value Cleaning

Replaces mathematical overflows (+Inf / -Inf from zero division in Flow Bytes/s) with safe feature maximums or medians.

3. Duplicate & Constant Pruning

Eliminates redundant packet logs and drops zero-variance constant features that carry zero discriminative power.

System Architecture & Mathematical Foundations

Semester 5 AI Project

1. Project Objective

CyberGuard ML resolves the challenges of modern network defense by utilizing a multi-tiered architecture: fast primary triage via Level 1 Binary Classification, fine-grained threat taxonomy via Level 2 Multiclass Classification with class probabilities, and continuous connection modeling via Level 3 Regression.

2. Confidence Score Computation

Unlike basic heuristics or regression-derived scores, the Attack Type Confidence Score (1–100%) is computed directly from the trained multiclass model's internal class posterior probabilities: Confidence = max(predict_proba(X)) * 100%.

3. Regression Formulations & Continuous Metrics

The regression pipeline predicts continuous connection flow parameters (such as Flow Duration or Flow Bytes/s) to establish behavioral baselines. It is evaluated using:

  • MAE (Mean Absolute Error): \(\frac{1}{n} \sum |y_i - \hat{y}_i|\)
  • MSE (Mean Squared Error): \(\frac{1}{n} \sum (y_i - \hat{y}_i)^2\)
  • RMSE (Root Mean Squared Error): \(\sqrt{\text{MSE}}\)
  • R² (Coefficient of Determination): \(1 - \frac{\sum (y_i - \hat{y}_i)^2}{\sum (y_i - \bar{y})^2}\)
